# tio-edu-site — session handoff

Public, WhatsApp-shareable revision site for Gino's children (聖羅撒書院 Form 2, 2026-27 First Term Uniform Test; Band 1 level). Static GitHub Pages, vanilla JS, **no build step in the browser**. Pages are generated by Python scripts in `tools/gen/`.

Read first: `docs/PLAYBOOK.md` (how every page is made), `docs/ARCHITECTURE.md` (files, engine API, i18n, theme), `docs/CONTENT-STATUS.md` (what is done / checked / missing). The plan for reusing this in the Tio Edu app is `docs/TIO-EDU-APP-PLAN.md`.

## Quick start
```
./tools/gen/build.sh                 # regenerate every generated page + fix meta descriptions
python3 -m http.server 8765          # preview at http://localhost:8765/ (run from repo root)
node tools/gen/test-geo-food.example.js   # example Playwright smoke test (needs `playwright`)
```
Edit content in `tools/gen/*.py` (never hand-edit generated `index.html` files except `index.html`, `works/index.html`, `works/typhoon-memory-route/`, `works/assets/*`). Check `git diff --stat` after a build: a no-op build must show no changes.

## Rules that must hold
- The user (Gino) speaks Cantonese; reply in Cantonese. UI text is Traditional Chinese (HK). English twin pages for every subject except 中文 and 中史普通話 (exam papers are fully English).
- Content comes from the user's own material (textbook photos/PDFs, past papers, school notes). Never invent syllabus facts. When textbook and school marking scheme disagree, show both and follow the marking scheme (example: Laos upland rice — textbook Table 4 ticks extensive, 2025-26 UT Q3 answer = high labour input).
- Do not commit textbook scans or exam papers to this public repo (only the derived notes/questions).
- Questions must be Band 1 level (users found early ones too easy): standard questions + `h` (hard/challenge) questions; AI-written questions are labelled 【AI 出題】.
- Timer must be switchable (children are stressed by timing); every game keeps a best score key.
- After changes: run the build, smoke-test with Playwright (no pageerrors, tabs work, EN pages contain no stray Chinese), then commit and push to `main`.
- Commit trailers: `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>` and `Claude-Session: <session url>`.
