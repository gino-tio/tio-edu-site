1. Type 1 — possible situations 可能發生嘅情況

If + simple present, simple future (will)

Talk about a possible situation: If it rains, we will cancel the outing.　If they have time, they will go to the cinema.
講有可能發生嘅情況：if 子句用現在簡單式，主句用將來簡單式。

Either clause can come first. Main clause first → no comma: We will cancel the outing if it rains.
兩個子句次序可以對調；主句喺前面就唔使逗號。

Common error No will in the if-clause: ✘ If you will join … → ✔ If you join the programme, you will get a 10% discount.
if 子句入面唔可以用 will。

2. Modals in Type 1 主句用情態動詞

If + simple present, modal + base verb

ModalUseExample
can / maypermissionThe tourists can/may see the exhibition if they pay.
maypossibleIf we forget our books, the teacher may punish us.
should / mustnecessary (must = stronger)If you want to borrow books, you must bring your card.
should / mustadviceYou should practise hard if you want to join the team.

If you get up late, you may miss the bus.

3. Type 0 — facts 事實

If + simple present, simple present

Talk about facts or general truths: If it rains, the ground gets wet.　If flowers do not get enough water, they die.
講事實或一般真理：兩個子句都用現在簡單式。

Order can change: The ground gets wet if it rains.
次序可以對調。

when can replace if: When flowers do not get enough water, they die.
Type 0 入面 when 可以代替 if。

If you press this button, the rice cooker starts cooking.　Ice melts if you take it out of the freezer.
