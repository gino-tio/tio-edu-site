2. Using comparatives and superlatives 用法

comparative + than　·　the + superlative + in / of

Compare two things: Tom is taller than Ben.
比較兩樣嘢用 comparative + than。

Compare three or more: Tom is the tallest in the class. / the tallest of the three.
三樣或以上用 the + superlative（in + 一個地方／組別；of + 一組人或物）。

Make it stronger or weaker with much / far / a lot / a bit / slightly + comparative: far bigger, slightly cheaper.
加強或減弱用 much／far／a lot／a bit／slightly。

Never say very bigger, more bigger or the more big.
唔可以講 very bigger、more bigger。

3. Making comparisons 作出比較

as … as　·　not as … as　·　less … than　·　the same … as　·　different from　·　similar to

PatternExampleMeaning
as + adj + asLily is as tall as Amy.equal
not as + adj + asThe red bag is not as expensive as the blue bag.red is cheaper
less + adj + thanThe red bag is less expensive than the blue bag.same meaning as above
the same + noun + asTom is the same age as Ben.equal
different fromMy bag is different from yours.not alike
similar toMy bag is similar to yours.almost alike
twice as + adj + asThe new library is twice as big as the old one.2 × the size
