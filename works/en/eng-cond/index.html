1. Type 0 — facts

If + present simple, present simple

Use it for facts and things that are always true.

If you heat ice, it melts.　If you press this button, the machine stops.

When can replace if in Type 0: When you heat ice, it melts.

2. Type 1 — possible situations

If + present simple, will + base verb

Use it for a possible situation in the future and its result.

If it rains tomorrow, we will stay at home.

No will in the if-clause: If it rains, not If it will rain.

The main clause can also use can / may / might / should or an imperative: If you are free, come and help me.

3. if, unless and punctuation

unless = if … not

Unless you hurry, you will miss the bus. = If you don’t hurry, you will miss the bus.

Do not use a negative verb after unless.

If the if-clause comes first, put a comma: If it rains, we will stay. No comma when it comes second: We will stay if it rains.
